# Quick Start

This is the stable documentation entry point for creating and validating a
first ALX Block.

The maintained runnable walkthrough is
[`integrators/typescript-sdk-quick-start.md`](./integrators/typescript-sdk-quick-start.md). The walkthrough
covers SDK installation, Block creation, validation, parent relationships, and
the next integration steps.

For protocol implementation rather than application integration, use
[`implementation-guide.md`](./implementation-guide.md).
