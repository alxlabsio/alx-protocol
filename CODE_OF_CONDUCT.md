# Code of Conduct

This document defines community standards for ALX Protocol spaces. This document does not define protocol behavior.

---

## Our Pledge

ALX Protocol is maintained as an open, technical, and professional project.

We are committed to a welcoming and productive environment for contributors, implementers, reviewers, and adopters, regardless of background or experience level.

## Standards

Expected behavior includes:

- constructive technical feedback;
- respect for different viewpoints and implementation approaches;
- focus on ALX Protocol correctness and adopters;
- clear, precise, and good-faith communication.

Unacceptable behavior includes:

- harassment, personal attacks, or discriminatory language;
- publishing another person’s private information without consent;
- sustained disruption of issues, pull requests, discussions, or review processes;
- conduct that would be inappropriate in a professional technical setting.

## Scope

This Code of Conduct applies to ALX Protocol project spaces, including GitHub issues, pull requests, discussions, reviews, and project-related communication channels.

## Enforcement

Reports may be sent to:

opensource@xandrlabs.ai

Maintainers will review reports, respond appropriately, and handle reports confidentially.
