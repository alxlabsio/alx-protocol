# ALX Content Profiles

Status: Active  
Audience: Implementers  
Authority: Non-core profile guidance

Profiles define optional semantic contracts for content stored inside `Block.content`.

Profiles do **not** change core Block validity, identity, hashing, lineage, or conformance. They exist so machines can safely interpret richer content when a Block elects to use a known profile.
